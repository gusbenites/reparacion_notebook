# Reparación de Notebooks

Skill de diagnóstico y reparación a nivel componente de placas madre de laptops, basado en la metodología de los canales de YouTube **Xtreme PC RGB**, **Daniel Bustamante Sensei**, **MetadataVE** (Leonardo García) y **ElectroSotox**.

## Estructura

```
skills/notebook-repair-diagnostics/
├── SKILL.md (enrutador principal + flujo maestro de diagnóstico)
└── references/
    ├── quick-cases-routing.md   ← ⚡ Punto de entrada rápido (síntoma → causa → archivo)
    ├── power-input-and-charger.md
    ├── buck-converters-and-ldo.md
    ├── power-sequence-ec-pch-ram.md
    ├── components-shorts-and-bios.md
    ├── video-catalog-cases.md
    ├── bustamante-advanced-techniques-and-macbook.md
    ├── metadataVE-advanced-bios-and-diagnostics.md
    └── electrosotox-errors-and-techniques.md
```

## Uso

1. **El equipo llega** → Observa el síntoma principal
2. **Mide el consumo** en la fuente de laboratorio
3. **Busca en `quick-cases-routing.md`** → Obtén la causa probable y el archivo a consultar
4. **Carga el archivo de referencia** con `read` para obtener la metodología detallada
5. **Sigue el flujo paso a paso** para confirmar la causa raíz
