## 2. Stock Esencial de Componentes SMD e Integrados para Taller

Según la recopilación de **Xtreme PC RGB** (`jc-VPEco2x4`), este stock cubre entre el 80% y 90% de las reparaciones de placas de laptop y gráficas:

- **kits de Resistencias SMD**: Encapsulados **`0201`, `0402`, `0603`, `0805`, `1206`**.
- **Controladores de Carga (Charger ICs)**:
  - Texas Instruments: **`BQ24780S`**, **`BQ24800`**
  - Intersil / Renesas: **`ISL88739A`**, **`ISL9241H`**, **`ISL9538H`**, **`ISL9552H`**
- **Controladores PWM de Fuentes Buck**:
  - Fuentes de 3.3V y 5V Always: **`TPS51225C`** (código Richtek equivalente: `3GS` / `3G=2C`), **`RT6575AG`**
  - Fuentes de Memoria RAM: **`RT8231A`** (código Richtek: `24=7G`)
  - Fuentes de CPU / GPU (VCORE / NVVDD): **`NCP81610`**, **`uP9511P`**
- **MOSFETs de Potencia (SOIC-8 / DFN 5x6 / 3x3)**:
  - **Canal N**: **`AON6992`**, **`QM3018M` (`QA3118`)**, **`PKCH2BB`**
  - **Canal P**: **`SI7617DN`**, **`AON7409`**
- **Dual MOSFETs / DrMOS (Driver + High-Side + Low-Side integrados)**:
  - **`NCP302155`**, **`AOZ5311NQI`** (código `BLN0`)
- **Controlador USB-C Power Delivery (PD)**:
  - **`TPS65994`** *(requiere programación o extracción de placa donante)*
